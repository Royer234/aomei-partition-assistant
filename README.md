## 🔧 Main Features

**Resize and move partitions.** Shrink a crowded drive and hand the freed space to a neighbour, all in one pass, without losing the files on either side.

**Merge partitions.** Combine two adjacent sections into a single larger one when you no longer need the split.

**Split a partition.** Divide one large drive into two smaller ones, which is handy when you want a separate area for backups or media.

**Create and delete partitions.** Make a new partition in unallocated space, or remove one you no longer use, then reuse the space elsewhere.

**Format partitions.** Prepare a partition with a file system so Windows can read and write to it.

**Clone a disk or partition.** Copy an entire drive to another drive, useful when moving from an older hard disk to a faster SSD.

**Migrate the operating system.** Move your Windows installation to a new drive without reinstalling everything from scratch.

**Convert between MBR and GPT.** Switch disk layouts when a drive needs to match the requirements of a newer system.

**Check and repair partitions.** Scan a partition for errors and fix common file system problems.

**Wipe a partition.** Permanently clear the contents of a partition when you plan to give a drive away.

**Allocate free space.** Pull unused space from one partition and add it to another in a guided, visual way.

## 🪟 Windows Compatibility

The application is built for Windows desktop and laptop computers. It works with both 32-bit and 64-bit systems and supports the Windows versions most people are running today, including Windows 11, Windows 10, Windows 8.1, and Windows 7.

Plan on roughly 100 MB of free disk space for the application itself, plus a little extra working room for the operations you queue up. Administrator rights are needed to change partitions, because those changes reach the low-level layout of your drive. Windows will ask for that permission when the tool starts, and approving it is normal.

Before you begin any large operation, back up the files you care about most. This is good practice for any partition work, no matter which tool you use.

## ❓ Common Questions

**Will my files be deleted?** Resizing, moving, and merging are designed to keep existing files in place. Formatting and wiping intentionally remove data, so read the confirmation message before you agree to it.

**Can I undo a change?** Changes take effect after you press the apply button. Review the queued operations in the preview area before that step, because once the work completes, reversing it means performing another operation.

**Do I need to restart my computer?** Most changes happen without a restart. Operations that touch the system partition may ask for one so the work can complete safely during the next startup.

**Is it safe to use on a laptop?** Yes, as long as the laptop stays plugged in and awake during an operation. Battery level drops plus partition work is a poor combination.

**Where do I get updates?** The download page always hosts the newest builds, so check back there when you want the latest version.

## 🛠️ Troubleshooting Tips

If the application does not open, make sure you approved the Windows permission prompt and that your antivirus software did not quietly block the file.
